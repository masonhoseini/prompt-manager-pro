# 📝 Prompt Manager Pro

A professional Chrome extension for managing AI prompts. Save, organize, and quickly access your prompts for ChatGPT, Claude, and other AI tools.

## ✨ Features

- 💾 **Save Unlimited Prompts** - Store all your favorite AI prompts
- 📁 **Folder Organization** - Group prompts by category or project
- 🔍 **Quick Search** - Find prompts instantly
- 📋 **One-Click Copy** - Copy prompts to clipboard with a single click
- ✏️ **Easy Editing** - Update prompts anytime
- 📥 **Export/Import** - Backup and restore your prompts as JSON
- 🎨 **Modern UI** - Clean, professional interface
- 🔒 **Privacy First** - All data stored locally, no cloud sync

## 🚀 Installation

### Method 1: Install from Source (Developer Mode)

1. Download or clone this repository
   ```bash
   git clone https://github.com/masonhoseini/prompt-manager-pro.git
   ```

2. Open Chrome and go to `chrome://extensions/`

3. Enable **Developer mode** (toggle in top right)

4. Click **Load unpacked**

5. Select the extension folder

6. Done! The extension icon will appear in your toolbar

### Method 2: Install from Release

1. Download the latest `.zip` file from [Releases](https://github.com/masonhoseini/prompt-manager-pro/releases)
2. Extract the ZIP file
3. Follow steps 2-6 from Method 1

## 📖 Usage

### Adding a Prompt

1. Click the extension icon
2. Go to **Add New** tab
3. Enter folder name (optional), title, and prompt text
4. Click **Save Prompt**

### Using Your Prompts

1. Click the extension icon
2. Go to **Library** tab
3. Browse or search for your prompt
4. Click **Copy** to copy to clipboard
5. Paste into your AI chat

### Managing Prompts

- **Edit**: Click the edit button to modify a prompt
- **Delete**: Remove prompts you no longer need
- **Search**: Use the search box to filter prompts
- **Export**: Backup all prompts to a JSON file
- **Import**: Restore prompts from a backup file
